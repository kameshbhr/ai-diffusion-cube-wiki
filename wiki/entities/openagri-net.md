# OpenAgriNet

**Type:** System / DPG ecosystem
**Role:** Open-source AI infrastructure for agricultural advisory at scale
**Geography:** India (primary); international (Ethiopia ATI first cross-geography deployment)
**Contact or reference:** openagri.net

## What they are

OpenAgriNet (OAN) is an open-source digital public goods ecosystem designed to enable AI-powered agricultural advisory at scale across different geographies, languages, and institutional contexts. It is not a single system — it is a suite of interoperable DPGs: the Knowledge Engine, Memory Layer, Trust Layer, Agent Core, Action Gateway, Reach Layer, Learning Layer (the seven core DPGs) plus Signal DPG, Aggregator DPG, and Facilitator DPG. These building blocks can be assembled and contextualised by any deployer without rebuilding the underlying infrastructure. The OAN architecture follows open-source, open-protocol principles throughout — no single-vendor dependency, no centralised data store, Beckn protocol for open network interoperability.

The OAN pathway is the mechanism by which MahaVistaar's nine months of pioneer work compressed to three months for Ethiopia ATI and three weeks for Amul Sarlaben. The DPG library is the transferable asset; the deployment knowledge is codified in governance frameworks, failure mode libraries, and deployment playbooks maintained by the OAN ecosystem.

## When this entity is relevant to an adopter

An adopter building agricultural AI advisory who wants to use existing, proven, open-source infrastructure rather than starting from scratch. OpenAgriNet provides the DPG library that makes compression possible; it is the technical answer to "what do I build with?" Any country or state deploying agricultural AI advisory should evaluate whether the OAN DPG library applies to their context before designing a custom architecture.
