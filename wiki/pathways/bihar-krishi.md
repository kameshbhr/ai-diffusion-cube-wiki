## Summary

Bihar Krishi is a state-level AI agricultural advisory deployment by the Government of Bihar. Compared to MahaVistaar, which uses the OAN DPG architecture with EkStep Foundation as network orchestrator, Bihar Krishi is an independent state deployment — providing a comparison data point on what differs when a state builds without the OAN DPG layer. Available documentation on this deployment is thin; most evidence in the OAN sources is comparative rather than detailed. A priority for this wiki is to deepen Bihar Krishi documentation so the DPG reuse value can be quantified through the comparison.
